# Verilog 模块结构与连线管理工具原始需求文档

日期：2026-05-13

## 1. 背景

当前 Verilog/SystemVerilog 项目中的模块结构、实例化关系、端口连线、参数配置通常分散在 RTL 文件、Excel 表格、手绘框图和工程师经验中。随着模块数量增加，人工维护顶层连线容易出现漏连、错连、位宽不匹配、多驱动、悬空端口等问题。

本项目希望建立一种适合 AI 与人类共同维护的模块结构管理方式：AI 看到的是结构化数据，人类看到的是表格和图形界面，最终可以稳定生成 Verilog 结构代码。

## 2. 核心目标

1. 建立 Verilog 模块、端口、实例、网络、连接、参数的结构化描述方式。
2. 支持 AI 读取、分析、修改模块结构与连线关系。
3. 支持人类通过 Excel 批量导入、导出和审查数据。
4. 支持人类通过图形界面查看模块拓扑和编辑连线。
5. 支持从结构化数据生成顶层 Verilog/SystemVerilog 例化代码。
6. 支持从已有 Verilog/SystemVerilog 代码中提取模块例化所需的端口、参数、位宽等接口信息。
7. 支持自动校验连接合法性，降低人工维护错误。

## 3. 典型用户

| 用户角色 | 关注点 |
| --- | --- |
| RTL 工程师 | 端口定义、实例连接、参数配置、生成代码可读性 |
| 架构设计人员 | 模块层级、数据通路、控制通路、接口关系 |
| 验证工程师 | 信号完整性、悬空端口、多驱动、位宽一致性 |
| AI 助手 | 结构化输入、局部修改、可校验输出 |

## 4. 功能需求

### 4.1 模块结构管理

- 维护模块定义，包括模块名、描述、分类、来源文件。
- 维护端口定义，包括端口名、方向、位宽、类型、时钟域、复位域、说明。
- 维护模块实例，包括实例名、模块类型、层级路径、参数覆盖。
- 维护内部 net/wire/logic，包括名称、位宽、类型、说明。
- 维护实例端口到 net 的连接关系。

### 4.2 已有 Verilog 接口提取

- 支持扫描已有 Verilog/SystemVerilog 源文件，提取 module 定义。
- 支持提取模块参数，包括参数名、默认值、表达式文本和可选说明。
- 支持提取模块端口，包括端口名、方向、位宽表达式、数据类型和声明来源。
- 支持将提取结果写入结构化 IR，供用户在 Excel 或图形界面中选择模块并创建实例。
- 支持对无法解析或包含复杂宏、generate、接口类型的模块给出告警，而不是静默生成错误数据。
- 初期重点提取“例化需要的信息”，不要求完整理解 RTL 行为逻辑。

### 4.3 Excel 导入导出

- 支持将结构化数据导出为 Excel 工作簿。
- 支持从 Excel 工作簿导入模块、端口、实例、连接、参数等表。
- 支持工程师批量修改连接表后重新导入。
- 导入时需要进行字段校验、引用校验和语义校验。

### 4.4 AI 协同

- AI 应修改结构化 IR，而不是直接修改生成后的 Verilog。
- AI 输出应受到 JSON Schema 或等价约束限制。
- 支持局部上下文输入，例如只给 AI 当前模块的实例和连接片段。
- 支持修改后自动校验并生成差异报告。

### 4.5 可视化查看与编辑

- 支持以模块实例为节点、信号连接为边显示拓扑。
- 支持端口级连接显示。
- 支持拖拽节点位置。
- 支持通过鼠标创建、删除或修改连接。
- 支持高亮悬空端口、位宽不匹配、多驱动等问题。
- 支持图形布局信息与结构数据分离，避免 UI 坐标污染核心设计数据。

### 4.6 Verilog 生成

- 从结构化 IR 生成顶层或子系统 Verilog/SystemVerilog 文件。
- 支持模块例化、参数覆盖、端口映射、wire/logic 声明、assign 生成。
- 支持生成前校验，校验失败时拒绝输出或标记风险。
- 生成文件应尽量稳定，便于 Git diff。

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 可维护性 | 数据模型清晰，便于脚本、AI 和人类共同理解 |
| 可扩展性 | 支持从单文件扩展到多模块、多层级、多文件 |
| 可追踪性 | 结构化文件适合 Git diff 和代码审查 |
| 可恢复性 | Excel、IR、图形布局之间可以重新生成或修复 |
| 可校验性 | 支持 schema 校验和硬件语义校验 |
| 易用性 | 工程师可以继续使用 Excel 批量编辑 |

## 6. 初始范围

第一阶段优先实现：

1. Excel 与结构化 IR 双向转换。
2. IR schema 定义。
3. 基础语义校验。
4. 从已有 Verilog/SystemVerilog 提取模块端口、参数、位宽等接口信息。
5. IR 到 Verilog 顶层结构代码生成。
6. IR 到 Mermaid 或 Graphviz 拓扑图生成。

第一阶段暂不强制实现完整 Web 图形编辑器，但数据模型需要为后续 React Flow 编辑器预留字段和接口。

## 7. 暂不纳入范围

- 完整 RTL 行为逻辑生成。
- 完整 EDA 替代工具。
- 复杂综合、时序、形式验证流程。
- 完整 IP-XACT 兼容。
- 多人实时协同编辑。

## 8. 验收标准

1. 可以通过 Excel 定义一个包含多个模块实例和连接关系的设计。
2. 可以导入 Excel 并生成合法的结构化 IR。
3. 可以对 IR 进行 schema 和基础语义校验。
4. 可以从已有 Verilog 模块文件提取端口、参数和位宽信息，并写入 IR。
5. 可以从 IR 生成可读的 Verilog 顶层文件。
6. 可以从 IR 生成可视化拓扑图。
7. AI 可以基于 IR 修改连接关系，并通过校验器发现明显错误。
